## 역할

PayPlay OSP는 **Website 중심 온라인 영업 플랫폼**이다.

온라인에서 유입(Traffic)을 확보하고, 영업 콘텐츠로 전환(Conversion)시켜
Lead를 확보한 뒤 OC로 Handoff하는 것이 핵심 역할이다.

---

## 담당 영역

```
PayPlay OSP (Online Sales Platform)
│
├─ Traffic / Acquisition       유입 확보
├─ Website / Sales Content     영업 콘텐츠·웹사이트
├─ Discovery                   탐색·발견
├─ Conversion                  전환
├─ Lead Capture                Lead 확보
├─ OSP → OC Handoff            OC로 Lead 인계
├─ Attribution / Analytics     성과 귀속·분석
└─ Marketing Decision / Admin  마케팅 의사결정·관리
```

---

## 경계 원칙

| 구분 | 내용 |
|------|------|
| OSP가 담당하는 것 | Traffic, Website, Discovery, Conversion, Lead Capture, Attribution, Analytics, Marketing Decision |
| OSP가 담당하지 않는 것 | 사람 상담 실행, 계약 실행 State, 설치·CS·AS 운영 |

> **OSP는 Lead 생성 / 유입 Source Owner이며, 사람 상담·계약 실행 State의 Master가 아니다.**
> Lead Handoff 이후의 영업 실행은 OC가 담당한다.

> ⚠️ **POS · 테이블오더 · 키오스크 · 카드단말기는 OSP 하위 구조가 아니다.**
> 해당 하드웨어 제품은 별도 Product 체계로 관리하며 OSP 구조와 혼합하지 않는다.

---

## Handoff

| 방향 | 내용 |
|------|------|
| OSP → OC | Lead / 유입 Source / Request Handoff |
