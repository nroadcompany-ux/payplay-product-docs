## Definition
PayPoint는 매장과 고객의 관계를 생성하고, 혜택과 참여를 통해 관계를 성장시키며 실제 행동과 경제적 결과를 측정하는 Customer Growth Product로 연구한다.

## Consumer Positioning Working Baseline
- 고객 혜택 브랜드
- 자주 가는 매장의 혜택을 모으고 사용하는 서비스
- 장기 메시지 후보: `잃어버린 내 돈(포인트) 찾기, PayPoint`

## Merchant Value
고객 연결 → 식별 → 관계 기억 → 혜택 → 참여 → 재방문/단골 → 결과 측정

## Core Candidate
Customer Entry / Relationship / Memory / Identification / State / Loyalty / Benefit / Engagement / Growth / Customer Asset / Attribution

## Strategic Expansion
QR/NFC Order, Pre-order, Scheduled Pickup/Dine-in, PG Payment, Receipt Review, POS Integration, Future Delivery.

## Out of Scope
POS 원천 결제 인프라, PG/VAN Network, Settlement Ledger, Rider 운영, NAVER 리뷰 작성·게시, Shared Master 물리 소유권.
