## Customer Growth
Entry → Identification → First Visit → Second Visit → Repeat → Regular → Risk Detection → Reactivation.

## Merchant Daily
오늘의 고객 브리핑 → 위험/휴면/2차 방문 후보 → 추천 Action → Message/Coupon/Event → 고객 반응 → Visit/Order/Payment → Attribution → Customer Asset Update.

## Pre-order
QR/Link → Store Gateway → Dine-in/Takeout → 시간 선택 → 메뉴 → 선결제 → Payment Success → Order Confirmed → POS/Kitchen.

## Receipt Review
QR → 영수증 신청 → Printer Task → 직원 전달 → NAVER Outbound → 고객 직접 리뷰.
